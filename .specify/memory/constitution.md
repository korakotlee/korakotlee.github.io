# korakotlee.github.io Constitution

## Core Principles

### I. Simplicity & Minimalism
Design should be clean, distraction-free, and focused on content. Avoid unnecessary complexity in both code and UI.

### II. Content-First
The primary goal is to showcase work. Content must be legible, accessible, and structured logically.

### III. Tech Stack Alignment
**Jekyll**: Use standard Jekyll directory structure and Liquid templating.
**Pure.css**: Use Pure.css (v0.5.0) for grid and layout primitives. Do not introduce conflicting frameworks.
**SCSS**: Use SCSS for custom styling, leveraging existing variables (e.g., `$color-pink`, `$color-blue`) in `css/main.scss`.

### IV. Performance & Responsiveness
The site must load fast and render correctly on all device sizes. Use Pure.css responsive grids.

### V. Maintainability
Code should be organized, commented where necessary, and easy to update. Keep assets in `img/` or `files/`.
